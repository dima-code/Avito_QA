# Список найденных багов
Приоритеты: P0 — критический, P1 — высокий, P2 — средний, P3 — низкий.

## Приоритет P0 (Критический)

Критических багов не выявлено, поскольку найденные баги не блокируют работу сайта, не приводят к ошибкам и не приводят к падению сайта.

## Приоритет P1 (Высокий)

### 1) Отображаются товары, не входящие в ценовой диапазон
**Описание бага**  
В списке объявлений пользователь видит объявления, не входящие в заданный ценовой диапазон.

**Шаги воспроизведения**
1) Открыть сайт Авито (https://www.avito.ru)  
2) Выбрать категорию товара (Животные - Кошки)  
3) Задать фильтры (Возраст - "Котенок", Пол - Мальчик, Цена - от 1000 до 30 000, Порода - "Персидская")  
4) Обратить внимание, что среди объявлений есть объявления, не подходящие под фильтр цены

**Ожидаемый результат**  
Пользователь видит объявления в рамках ценового диапазона.

**Фактический результат**  
Пользователь видит объявления, не входящие в заданный ценовой диапазон.

**Обоснование**  
Баг ломает важный пользовательский сценарий (фильтрация по цене), пользователь получает нерелевантную выдачу.
